Install Freeglut on your system and open your MSYS2 shell and navigate to the Windows folder. Run the MAKE command locaated in the Windows folder.

To install freeglut under MSYS2 run the following command in the MSYS2 shell: pacman -S mingw-w64-x86_64-freeglut

Move to the Debug folder and run the clock by typing: ./AnalogClock.exe from the MSYS2 shell.
If running the binary from the Windows command prompt or by double-clicking on the EXE, make sure that libfreeglut.dll is also in the Debug folder
